# KDK Spectrum Cloud - Clients Without DSC

Static GitHub Pages-ready mockup.

## Run locally
Open `index.html` in a browser.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`.
3. Go to Settings -> Pages.
4. Select `Deploy from a branch`.
5. Select `main` and `/root`.
6. Save.

## Included
- Clients without DSC dashboard
- Summary cards
- Search
- Organisation Type / State / Client Status filters
- Pagination
- Select-all checkbox
- Export to CSV (Excel-compatible)
- Add DSC modal
- Responsive horizontal table
- Mock client data

The mock currently uses static data. Replace the `clients` array / render logic with your API response when the backend API is available.
